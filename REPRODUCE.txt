Source installation:
After installing the pinned dependencies in a separate fresh environment,
replace the wheel-install command with:
  python -m pip install --no-build-isolation --no-deps ./executable_assurance_reference-0.1.8rc6.tar.gz
Use that environment's interpreter for the same test command. A normal,
non-editable installation from a clean repository clone is also supported:
  python -m pip install --no-build-isolation --no-deps /path/to/clone

Offline installation:
Use the wheelhouse for the matching operating system and Python ABI, with its
accompanying requirements-offline.lock. The lock pins every dependency and the
application wheel. Do not substitute wheels for another platform or Python ABI.
  python -m pip install --no-index --find-links /path/to/wheelhouse --require-hashes -r /path/to/requirements-offline.lock
Then run the same full public-suite command with the offline environment.
