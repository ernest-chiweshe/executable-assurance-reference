# Security policy

Report a suspected vulnerability privately, never in a public issue:

- through GitHub's **Report a vulnerability** button on this repository's Security tab, or
- by email to [ernest.chiweshe@lumiwright.com](mailto:ernest.chiweshe@lumiwright.com).

Include the release, the steps to reproduce and the effect you observed.

The latest release is supported. This repository is a reference implementation that runs synthetic local demonstrations against an isolated database; it is not a hosted service. Deploy it only on vendor-patched Python interpreters and operating-system libraries.
